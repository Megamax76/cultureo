## Cohérence Interne

### Checklist de Cohérence

- [ ] Tous les arguments supportent la thèse principale
- [ ] Pas de contradictions entre chapitres
- [ ] Les prémisses sont établies avant les conclusions
- [ ] Les termes clés sont utilisés de manière consistante
- [ ] Les objections majeures sont adressées
- [ ] La progression est cumulative (chaque chapitre s'appuie sur précédents)
- [ ] Les sauts logiques sont justifiés ou comblés

## Notes pour la Rédaction

### Pièges à éviter
- [ ] Affirmer sans prouver
- [ ] Généraliser hâtivement
- [ ] Ignorer contre-arguments évidents
- [ ] Utiliser raisonnement circulaire
- [ ] Confondre corrélation et causalité

### Stratégies rhétoriques
- Établir crédibilité tôt
- Anticiper objections
- Concéder points mineurs pour renforcer point principal
- Utiliser exemples mémorables
- Récapituler régulièrement
