# Projet de Livre - Structure Professionnelle

## Vue d'ensemble

Ce projet contient la structure complète pour écrire un livre intellectuel de haute qualité, organisé de manière professionnelle et cohérente.

## Structure du Projet

```
book/
├── README.md                    # Ce fichier
├── STRUCTURE.md                 # Documentation détaillée de la structure
├── style-guide.md              # Guide de style et conventions
├── progress-tracker.md         # Suivi de la progression
├── manuscript/                 # Manuscrit principal
├── chapters/                   # Chapitres individuels
├── outline/                    # Plans et structures
├── research/                   # Recherches et notes
├── resources/                  # Ressources et références
├── drafts/                     # Brouillons et versions
├── concepts/                   # Concepts clés et thématiques
├── bibliography/              # Bibliographie et citations
└── templates/                  # Templates réutilisables
```

## Workflow Recommandé

1. **Planification** : Commencer par `outline/` pour structurer vos idées
2. **Recherche** : Documenter dans `research/`
3. **Rédaction** : Écrire les chapitres dans `chapters/`
4. **Révision** : Sauvegarder les versions dans `drafts/`
5. **Compilation** : Assembler dans `manuscript/`

## Démarrage Rapide

1. Consultez `STRUCTURE.md` pour comprendre l'organisation
2. Lisez `style-guide.md` pour les conventions
3. Utilisez les templates dans `templates/`
4. Suivez votre progression dans `progress-tracker.md`

## Commandes Utiles

- Compter les mots : `wc -w chapters/**/*.md`
- Vérifier la structure : `tree book/`
- Rechercher : `grep -r "terme" chapters/`

## Objectifs

- ✅ Structure claire et modulaire
- ✅ Cohérence stylistique
- ✅ Traçabilité de la recherche
- ✅ Versionnement des drafts
- ✅ Documentation complète
