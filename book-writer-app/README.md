# Book Writer App

Application web d'écriture de livres avec éditeur riche de type Medium/Word.

## Fonctionnalités

- ✍️ Éditeur riche avec Tiptap (H1-H3, gras, italique, listes, citations)
- 📚 Gestion multi-livres
- 📖 Navigation par chapitres
- 💾 Auto-sauvegarde (localStorage)
- 🎨 Interface sobre et efficace

## Pré-chargé avec

Le livre **"Vibe Coding : Le Manifeste de la Création Numérique par l'Intention"** est automatiquement chargé au premier lancement avec :
- Préface complète
- Introduction complète
- Structure des 15 chapitres

## Développement local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000)

## Technologies

- Next.js 14
- TypeScript
- Tiptap (éditeur)
- Tailwind CSS
- Lucide React (icônes)
